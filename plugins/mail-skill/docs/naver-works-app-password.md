# 회사메일(NAVER WORKS) 앱 비밀번호 만들고 등록하기

AI 비서가 회사메일을 읽고 보내려면, 로그인 비밀번호 대신 **앱 비밀번호**(메일 프로그램 전용 비밀번호)가 하나 필요합니다. 처음 한 번만 하면 됩니다. 10분쯤 걸립니다.

> 화면의 메뉴 이름은 웍스 버전에 따라 조금 다를 수 있습니다. 아래 [그림] 자리는 나중에 스크린샷으로 바뀝니다.

## 준비물

- 회사메일 주소와 웍스 로그인 비밀번호
- 휴대폰(2단계 인증을 쓰는 경우)
- 이 PC 에 `jaix setup` 이 끝나 있을 것 (메일 프로그램·암호화 도구는 그때 같이 깔립니다)

## 1단계 — 웍스에서 앱 비밀번호 만들기

1. 웹 브라우저로 NAVER WORKS 에 로그인합니다.
2. 오른쪽 위 **내 프로필(사진 또는 이름)** 을 누르고 **보안 설정**(또는 **내 정보 → 보안**) 으로 들어갑니다.

   [그림 1: 프로필 메뉴에서 보안 설정 위치]

3. **앱 비밀번호**(또는 **외부 앱 비밀번호 / IMAP·SMTP 비밀번호**) 항목에서 **생성** 을 누릅니다.
4. 이름을 물으면 알아보기 쉬운 이름을 넣습니다. 예: `AI 비서 - 내 PC`
5. 화면에 나온 비밀번호를 **바로 복사**합니다. 이 화면을 닫으면 다시 볼 수 없습니다.

   [그림 2: 생성된 앱 비밀번호 화면]

- 이 메뉴가 보이지 않으면, 회사에서 IMAP/SMTP 사용을 막아 둔 것일 수 있습니다. 웍스 관리자에게 "IMAP/SMTP 사용과 앱 비밀번호 발급을 허용해 달라" 고 요청하세요.
- 복사한 앱 비밀번호는 메모장·메일·메신저에 붙여 두지 마세요. 2단계에서 바로 붙여 넣고 끝냅니다.
- 웍스가 보여주는 **복구 코드**가 있더라도 이 과정에는 필요 없습니다. 어디에도 입력하거나 저장하지 마세요.

## 2단계 — 내 PC 에 등록하기

**직접 연 터미널 창**에서 실행합니다. (AI 비서 채팅창에서 대신 실행하게 하면 비밀번호를 숨김 입력으로 받을 수 없어서 멈춥니다.)

- Windows: 시작 메뉴에서 **PowerShell** 을 열고
- Mac: **터미널** 앱을 열고

다음을 입력합니다.

```
mailskill setup
```

묻는 순서:

1. `회사 메일 주소` — 전체 주소를 넣습니다. 예: `hong@example.com`
2. `NAVER WORKS 앱 비밀번호` — 1단계에서 복사한 것을 붙여 넣고 Enter. **입력해도 화면에 아무것도 보이지 않는 것이 정상**입니다.
   - Windows PowerShell: 마우스 오른쪽 클릭 또는 `Ctrl+V`
   - Mac 터미널: `Cmd+V`

   [그림 3: mailskill setup 실행 화면]

마지막 줄에 `로그인 확인 완료` 가 나오면 끝입니다. AI 비서에게 "회사메일 최근 메일 보여줘" 라고 해 보세요.

## 이렇게 저장됩니다

- 앱 비밀번호는 이 PC 에서만 열 수 있는 열쇠로 **암호화해서** 저장합니다. 화면·기록·일반 파일에는 남지 않습니다.
  - 열쇠: `내 사용자 폴더\.config\mail-skill\age-key.txt` — 이 파일은 다른 곳에 복사하거나 보내지 마세요.
  - 암호화된 비밀번호: `내 사용자 폴더\.config\mail-skill\secrets.age`
- 메일 설정(주소·서버)은 `내 사용자 폴더\.config\himalaya\config.toml` 에 생깁니다.

## 잘 안 될 때

화면의 `->` 줄이 고치는 방법입니다. 자주 나오는 경우:

| 화면에 나온 말 | 할 일 |
|---|---|
| 필요한 프로그램이 없습니다 | `jaix setup` 을 먼저 실행합니다 |
| 직접 연 터미널(PowerShell 창)에서 실행해야 합니다 | 채팅창 말고 PowerShell/터미널 창을 직접 열어 실행합니다 |
| 로그인 실패 … 앱 비밀번호가 틀렸습니다 | 1단계에서 앱 비밀번호를 새로 만들고 `mailskill setup` 을 다시 실행합니다 |
| 메일 서버에 접속하지 못했습니다 | 인터넷 연결을 확인하고, 계속되면 웍스 관리자에게 IMAP/SMTP 허용을 요청합니다 |
| mail-secret 명령을 찾을 수 없어 … | `jaix setup` 을 다시 실행한 뒤 `mailskill doctor ji` 로 확인합니다 |

- `mailskill setup` 은 몇 번이고 다시 실행해도 됩니다. 앱 비밀번호만 새 것으로 바뀌고, 열쇠와 설정은 그대로 둡니다.
- 앱 비밀번호를 바꾸거나 PC 를 바꾸면 1단계부터 다시 하면 됩니다. 쓰지 않는 앱 비밀번호는 웍스 보안 설정에서 삭제하세요.
- 이 PC 에서 상태만 다시 확인하려면: `mailskill doctor ji`
